📖 Quick-Start User Guide

Welcome! This tool runs entirely inside your web browser. That means all your designs and employee records are saved directly to your computer, not to a remote server. Because of this, it's super fast, but you need to know how to export your work if you switch computers.

1. What is an Entity / Workspace?

When you first open the app, it asks for your Entity Name (e.g., "GymKoto"). This is basically just a folder name. Whatever you type here creates a specific save slot on your browser. If you type "Company A", you will only see Company A's designs. You can switch folders anytime by clicking [Switch Entity] at the top left.

2. Tab 1: Designing the Layout

  • Static vs. Database: When you click on any element (like a Text box or Barcode), look at the right-side panel.
    • If you set it to "Static", it stays exactly the same on every single ID card (like your company name or logo).
    • If you set it to "Database", the app knows this information changes for every person (like Employee Name, Profile Photo, or ID Number). Whatever you type in the "Database Column Name" box will instantly become a column in Tab 2.
  • Editing Text: Double-click any text box to type inside it. Press Escape on your keyboard when you are done. The text will automatically shrink if it gets too long!
  • Resizing: Click an item, then grab the tiny white circle in the bottom right corner to make it bigger or smaller.

3. Tab 2: The Database & Uploading from Excel

This tab is where you list all the people who need an ID card. Any element you set to "Database" in Tab 1 will show up as a blank field here.

  • Manual Entry: Just type their name, upload their photo from your computer, and click "Add to Database."
  • Bulk Import from Excel (The CSV Method): Have a list of 100 employees in Excel?
    1. Make sure your Excel columns exactly match the names in the app (e.g., "Full Name", "ID Number").
    2. In Excel, click File > Save As.
    3. Change the file type format to CSV (Comma delimited) (*.csv). This converts Excel into plain text.
    4. Come back to the app, look at the right-hand panel in Tab 2, and upload that `.csv` file. All 100 people will instantly appear in the table!

4. Syncing, Exporting, and Backing Up (JSON Files)

Because the app saves to your browser, if you clear your browser history or move to a completely different laptop, your work will be gone. To fix this, you must export your data. The app only accepts `.json` files for backups.

  • Export Project (Top Dark Bar): This is the ultimate backup. It saves your design layout, your background images, AND your entire list of people into ONE file. Email this `.json` file to yourself or a coworker, click Import Project on the new computer, and everything is instantly restored.
  • Export Database Only (Tab 2 left side): This ONLY saves the list of people (and their photos) to a `.json` file. It does not save the card design layout.

5. Tab 3: Printing

  • Print Cards Button: Click this to print your finished list. A print dialog will open.
  • Crucial Printer Settings: To ensure the cards line up perfectly on PVC printers (like Fargo or IDP Smart):
    • Set Scale to 100% (or "Actual Size").
    • Set Margins to None.
    • Turn OFF "Headers and Footers".
  • Print Raw Button (Design Tab): Only want to print the blank background design without any employee data on it? Go to Tab 1 (Design Layout) and click the blue 🖨️ Print Raw button on the sticky toolbar.

How to mass import employees:

2. Make sure your top row column headers match your Database Column Names exactly (e.g., "Full Name", "ID Number").

3. Click File > Save As and select the CSV (Comma delimited) format.

4. Upload that .csv file below to instantly generate a database record for every row in your spreadsheet.
